# TimeKernel 機能仕様書

> 最終更新: 2026-03-20
> バージョン: 1.0.0
> バンドルID: com.timekernel.app

## 概要

TimeKernelは大学生向けの総合カレンダー＆生活管理アプリです。予定管理、時間割、バイト管理、勉強記録、天気・交通情報を1つのアプリに統合しています。

---

## 1. カレンダー・予定管理

### 1.1 カレンダー表示
- **5つのビュー**: 月表示、週表示、日表示、3日表示、アジェンダ表示
- **月表示**: カレンダーグリッドが画面いっぱいに広がり、各セルに最大4件のイベントチップを表示
- **複数日イベント**: 開始日〜終了日にまたがる1本の連続バーとして表示
- **スワイプ**: 左右スワイプで月移動
- **年月ピッカー**: ヘッダーの年月タップでカレンダー形式の年月選択モーダル
- **日付の色分け**: 日曜・祝日は赤、土曜は青（日本の祝日に完全対応）
- **時間割トグル**: ヘッダー行で時間割イベントの表示/非表示を切替

### 1.2 イベント管理
- **イベントタイプ**: 予定(赤)、授業(青)、バイト(緑)
- **終日イベント**: 終日トグルONで時間入力不要、複数日選択可能
- **繰り返し**: 毎日、毎週、隔週、毎月、カスタム間隔
- **カラー選択**: 24色のカラーパレット
- **詳細モーダル**: 日付ダブルタップで画面全体にイベント一覧を表示
- **スワイプ削除**: イベントカードを左スワイプで削除（確認ダイアログ付き）
- **アバター表示**: イベントカードに作成者のアバターを表示（共有カレンダー対応）

### 1.3 スマート入力（音声・テキスト）
- **自然言語パース**: 「明日 14時 歯医者」→ 自動でイベント作成
- **対応パターン**: 今日/明日/来週/X日後/X月Y日/毎週X曜/今月のX曜
- **時間範囲**: 「9時から18時」のような範囲指定に対応
- **タイプ自動検出**: 「バイト」→shift、「授業」→class
- **一括作成**: 「今月の火曜 9時から18時 バイト」→ 今月の全火曜日に作成
- **削除コマンド**: 「今月の火曜 バイト 削除」→ マッチするイベントを一括削除
- **プレースホルダー**: 入力例が10秒ごとにスロット式アニメーションで切替表示
- **リアルタイムプレビュー**: 入力中に解析結果を表示

### 1.4 複数カレンダー管理
- **ローカルカレンダー**: 個人カレンダーはSQLiteにローカル保存
- **共有カレンダー**: 共有時にFirestoreに移行（バッチ書き込み対応）
- **カレンダー切替**: ヘッダーの矢印で切替、タブ長押しでチェックボックス式選択
- **複数選択**: 複数カレンダーのイベントを同時表示可能
- **カレンダー作成/参加/退出/削除**: フル管理機能

### 1.5 データ保存方式
- **個人カレンダー（members=1）**: SQLite（expo-sqlite）
- **共有カレンダー（members>1）**: Firestore
- **外部インポートイベント**: SQLite
- **eventService.ts**: ファサードパターンでローカル/Firestoreを自動ルーティング

## 2. 時間割

### 2.1 時間割管理
- **週間グリッド**: 月〜金（+土日）× 6時限のグリッド表示
- **科目編集**: セルタップで科目名・教室・カラーを設定
- **カレンダー連携**: 時間割をカレンダーにイベントとして表示（トグルで切替）
- **ローカル保存**: SQLiteに保存（Firestoreから移行済み）
- **将来: 共有機能**: カレンダーと同じパターンで共有化予定

### 2.2 時限設定
- デフォルト6時限（9:00〜19:30）
- 各時限の開始・終了時刻をカスタマイズ可能
- 設定 → 学校・バイト → 時限設定

### 2.3 大学ポータルリンク
- **時間割タブ下部に配置**: ポータルサイトへのクイックアクセス
- **プリセット**: manaba, Google Classroom, Microsoft Teams, Moodle, Universal Passport
- **カスタムURL登録**: 名前とURLを入力して追加
- **外部ブラウザで開く**: セキュリティのためWebViewは使用しない
- **免責表示**: 「URLの安全性はご自身でご確認ください」

## 3. 課題管理

### 3.1 課題タブ
- **課題タイプ**: レポート、試験、課題
- **期限管理**: カレンダーピッカー＋タイムピッカーで設定
- **ステータス**: 未着手 → 進行中 → 完了（タップでサイクル）
- **グルーピング**: 期限超過(赤) / 今日(橙) / 3日以内(黄) / それ以降(灰)
- **科目紐づけ**: 時間割の科目と連携
- **スワイプ削除**: 確認ダイアログ付き
- **完了アニメーション**: 紙吹雪エフェクト

### 3.2 課題通知
- 締切前通知（時間指定）
- 前日リマインダー
- 通知設定画面で一括管理

---

## 4. ポモドーロタイマー

### 4.1 タイマー機能
- **円形プログレス**: アニメーション付きの円形タイマー
- **時間プリセット**: 15/20/25/30/45/50/60分
- **フェーズ管理**: 集中 → 小休憩 → 集中 → ... → 大休憩
- **科目選択**: 時間割の科目から選択（未選択でも開始可能）
- **セッション記録**: 完了サイクル数、合計勉強時間を表示

### 4.2 勉強統計
- **折れ線グラフ**: 日別の勉強時間をSVGグラフで表示
- **期間切替**: 今日 / 今週 / 今月
- **今月表示**: 1日〜末日、1週間区切りでラベル表示
- **科目別内訳**: 横棒グラフで科目ごとの勉強時間を表示
- **1日平均**: 合計÷日数で自動算出
- **ストリーク**: 連続勉強日数の追跡

## 5. バイト管理

### 5.1 シフトタブ
- **月切替**: 左右矢印で月を切替
- **サマリーカード**: 見込み給料(大きく表示)、勤務時間、出勤日数、平均時間/回
- **曜日別チャート**: 縦棒グラフで曜日ごとの出勤回数を可視化
- **シフト一覧**: 日付・時間・勤務時間・給料を表示
- **シフト追加**: ＋ボタンからタイプ「バイト」固定で追加画面へ
- **スワイプ削除**: 確認ダイアログ付き

### 5.2 給料計算
- 時給 × 勤務時間で自動計算
- 深夜割増対応（設定で開始時刻・倍率をカスタマイズ）

### 5.3 バイト求人リンク
- **6つの求人サイト**: タウンワーク、バイトル、マッハバイト、シフトワークス、タイミー、マイナビバイト
- **アフィリエイト対応**: `.env` でアフィリエイトURLに差替可能
- **フォールバック**: 未設定時は通常の公式URLを使用

## 6. 天気・服装提案

### 6.1 天気表示
- **DashboardSummary**: カレンダー上部に天気アイコンと気温をチップ表示
- **天気詳細モーダル**: チップタップで詳細表示
  - 現在の気温・最高/最低・降水確率
  - 今後24時間の3時間ごと予報（現在時刻以降のみ表示）
  - 翌日ラベル付き
- **データソース**: OpenWeatherMap API（Current + Forecast）
- **キャッシュ**: 3時間TTLでAsyncStorageにキャッシュ

### 6.2 服装提案
- **予定連動**: 次の予定の時間帯の予報気温で提案
- **気温別提案**: 30℃以上→半袖 / 25℃→薄手の羽織 / 20℃→長袖 / 15℃→パーカー / 10℃→アウター / 5℃以下→防寒
- **傘の提案**: 降水確率50%以上で「☔ X時頃 降水確率Y% 傘を忘れずに！」
- **設定画面に提案ガイド表示**: 気温と服装の対応表

### 6.3 天気設定
- 天気表示ON/OFF
- 位置情報自動取得
- 朝の天気通知（時刻プリセット: 6:00〜8:00）
- 華氏/摂氏切替

---

## 7. 鉄道遅延情報

### 7.1 路線登録
- **設定画面**: 鉄道会社別に折りたたみ表示、検索機能付き
- **対応路線**: 80+路線（JR東日本、東京メトロ、都営、私鉄、新交通）
- **路線カラー**: 各路線の実際のラインカラーを表示
- **AsyncStorage保存**: ローカルに保存

### 7.2 遅延表示
- **DashboardSummary**: 遅延中の路線のみチップ表示（黄=遅延、赤=運休）
- **タップで検索**: 遅延チップタップで「会社名 路線名 運行情報」をGoogle検索
- **正常運行時**: 何も表示しない（ノイズゼロ）
- **データソース**: ODPT API（審査中、現在ダミーデータ）

## 8. 資格試験カレンダー

### 8.1 試験一覧
- **8カテゴリ**: 語学、IT、ビジネス・会計、法律、公務員、医療・福祉、建築・不動産、教育
- **80+資格**: TOEIC各級、英検各級、ITパスポート、簿記、FP、宅建、看護師 等
- **折りたたみUI**: カテゴリごとに開閉、購読数バッジ表示
- **検索機能**: 資格名・カテゴリ名で絞り込み
- **免責表示**: 「日程は変更される場合があります」を赤文字で表示

### 8.2 カレンダー連携
- 購読した試験の「試験日」「申込締切」がカレンダーに自動表示
- 試験日: 紫色、申込締切: 赤色
- 公式サイト検索リンク付き（Google検索にフォールバック）

### 8.3 データ自動更新
- **GitHub Actions**: 3ヶ月に1回自動実行（リリース時に有効化）
- **Claude API (Haiku)**: カテゴリ別に分割取得、年間コスト約¥88
- **CBT随時**: ハードコードでAPI不要
- **PR自動作成**: データ更新をPRとして作成、確認後マージ
