# TimeKernel v3 要件定義書

## 概要

v1（カレンダー・予定管理・共有・時間割・バイト計算・MCP・Apple Watch）、
v2（オフライン・ウィジェット・通知・外部カレンダー連携・UX強化・音声アシスタント・iPad対応）に加え、
v3では **生活支援機能（天気・服装提案、資格試験カレンダー）** を追加し、学生の日常をさらに便利にする。

> **優先度方針**: 実装コスト・API費用が低く、毎日使われる機能（天気・服装提案）を最優先。資格試験日はデータ整備が中心のため並行して進める。

---

## Phase 1: 天気・服装提案

### 目的
朝の外出前に天気と気温に基づいた服装アドバイスを表示し、「今日何着ていこう？」を解決する。

### 仕様

| 項目 | 内容 |
|------|------|
| 天気データソース | OpenWeatherMap API（無料枠: 1,000回/日） |
| 位置情報取得 | `expo-location` で現在地取得（許可時）。未許可時は手動で都市設定 |
| 表示場所 | カレンダーのヘッダー下（今日の天気カード） |
| 更新頻度 | アプリ起動時 + 3時間ごとバックグラウンド更新 |

### 天気カード表示内容

| 要素 | 内容 |
|------|------|
| 天気アイコン | 晴れ / 曇り / 雨 / 雪 etc. |
| 現在の気温 | ○℃ |
| 最高 / 最低気温 | ○℃ / ○℃ |
| 降水確率 | ○% |
| 服装提案 | 気温レンジに基づくアドバイス（下記参照） |

### 服装提案ロジック

| 気温帯 | 提案 |
|--------|------|
| 30℃〜 | 半袖・短パンでOK。日焼け止め忘れずに |
| 25〜29℃ | 半袖で快適。薄手の羽織があると冷房対策に |
| 20〜24℃ | 長袖シャツやカーディガンがちょうどいい |
| 15〜19℃ | パーカーや軽めのジャケットがおすすめ |
| 10〜14℃ | しっかりめのアウター必須。マフラーもあり |
| 5〜9℃ | コート + マフラー + 手袋で防寒 |
| 〜4℃ | 厚手コート + 防寒フル装備。ヒートテック推奨 |

> 雨の場合は「☔ 傘を忘れずに！」を追加表示

### 通知連携

| 項目 | 内容 |
|------|------|
| 朝の天気通知 | 毎朝設定時刻に天気 + 服装提案をプッシュ通知（デフォルト: 7:00） |
| 雨アラート | 降水確率が50%以上の場合、追加で傘リマインド |
| 通知ON/OFF | 設定画面から切り替え可能 |

### 技術方針

- OpenWeatherMap の [One Call API 3.0](https://openweathermap.org/api/one-call-3) または [Current Weather](https://openweathermap.org/current)
- APIキーは Firebase Remote Config または環境変数で管理（ハードコード禁止）
- レスポンスは AsyncStorage にキャッシュ（TTL: 3時間）
- `expo-location` の `requestForegroundPermissionsAsync()` で位置情報取得
- 服装提案ロジックは `src/utils/weatherClothing.ts` にて気温→メッセージのマッピング

### データフロー

```
[アプリ起動 / バックグラウンド更新]
    ↓
[expo-location で位置情報取得]
    ↓
[OpenWeatherMap API で天気取得]
    ↓
[AsyncStorage にキャッシュ]
    ↓
[天気カード表示 + 服装提案ロジック適用]
    ↓
[朝の通知スケジュール登録]
```

### 設定項目

| 設定 | デフォルト |
|------|-----------|
| 天気表示ON/OFF | ON |
| 位置情報 | 自動取得（手動設定も可） |
| 朝の通知時刻 | 7:00 |
| 朝の通知ON/OFF | OFF |
| 温度単位 | ℃（華氏切り替え可） |

## Phase 2: 資格試験カレンダー

### 目的
大学生がよく受ける資格試験の日程をカレンダーに表示し、申込み忘れや勉強計画の見落としを防ぐ。

### 仕様

| 項目 | 内容 |
|------|------|
| データソース | Firestore `examSchedules` コレクション（運営側で定期更新） |
| 対象資格 | 下記の主要資格（段階的に拡大） |
| 表示方法 | カレンダー上に試験日マーク + 申込み締切リマインド |
| 購読方式 | ユーザーが興味のある資格を選択して購読 |

### 対象資格（初期リリース）

| カテゴリ | 資格名 |
|----------|--------|
| 語学 | TOEIC L&R / TOEFL iBT / 英検 / IELTS |
| IT | ITパスポート / 基本情報技術者 / 応用情報技術者 |
| ビジネス | 簿記（2級・3級） / FP（2級・3級） / 秘書検定 |
| 法律 | 宅建 / 行政書士 |
| 公務員 | 国家一般職 / 地方上級 |

### 表示内容

| 要素 | 内容 |
|------|------|
| 試験日 | カレンダー上にアイコン + 試験名 |
| 申込み開始日 | カレンダー上にマーク |
| 申込み締切日 | カレンダー上にマーク + 締切○日前リマインド |
| 試験詳細 | タップで公式サイトへのリンク + 受験料 + 会場情報 |

### データ構造（Firestore）

```
examSchedules/{examId}
├── name: "TOEIC L&R 第XXX回"
├── category: "language"
├── examDate: Timestamp
├── applicationStart: Timestamp
├── applicationDeadline: Timestamp
├── resultDate: Timestamp (optional)
├── officialUrl: "https://..."
├── fee: "7,810円"
├── notes: "写真付き身分証明書必要"
├── year: 2026
└── tags: ["toeic", "language", "english"]

users/{uid}/subscribedExams
├── categories: ["language", "it"]
└── exams: ["toeic", "eiken", "fe"]
```

### リマインド通知

| タイミング | 内容 |
|-----------|------|
| 申込み開始日 | 「○○の申込みが始まりました」 |
| 申込み締切7日前 | 「○○の申込み締切まであと7日」 |
| 申込み締切1日前 | 「○○の申込み締切は明日！」 |
| 試験3日前 | 「○○の試験まであと3日。持ち物を確認しよう」 |
| 試験当日 | 「今日は○○の試験日。頑張って！」 |

### 技術方針

- 試験データは Firestore の `examSchedules` コレクションに格納（管理用のスクリプトまたは管理画面で更新）
- クライアントはユーザーの購読設定に基づいて `onSnapshot` でリアルタイム取得
- カレンダー上の表示は既存の `useMergedEvents` フックに統合
- 通知は既存の `notificationService.ts` を拡張

### 画面

| 画面 | 内容 |
|------|------|
| 資格試験一覧 | カテゴリ別に資格を表示。トグルで購読ON/OFF |
| 試験詳細 | 試験日・申込み期間・受験料・公式リンク等 |
| 設定 | リマインド通知のON/OFF・タイミング設定 |

## Phase 3: テスト・統合・リリース準備

### 目的
v3の全機能が正しく動作することを確認し、リリース可能な状態にする。

### 内容

| 項目 | 内容 |
|------|------|
| ユニットテスト | 服装提案ロジック・天気キャッシュ・試験データフィルタリング |
| 統合テスト | 天気API連携・通知スケジューリング・カレンダー表示統合 |
| E2Eテスト | 天気カード表示フロー・資格購読フロー |
| パフォーマンス | 天気APIキャッシュの効果検証・Firestoreクエリ最適化 |
| APIキー管理 | 環境変数 / Remote Config の設定確認 |

---

## MCP拡張（v3）

既存のMCPサーバーに以下のツールを追加:

| ツール名 | 説明 |
|----------|------|
| `get_weather` | 現在地の天気・気温・服装提案を取得 |
| `get_upcoming_exams` | 購読中の資格試験の直近スケジュールを取得 |

---

## 非機能要件

| 項目 | 内容 |
|------|------|
| API費用 | OpenWeatherMap無料枠内（1,000回/日）で運用 |
| プライバシー | 位置情報は端末内でのみ使用。サーバーに送信しない |
| オフライン | 天気データはキャッシュで閲覧可。試験データはFirestoreオフラインパーシステンスで対応 |
| 国際化 | 天気は多言語対応（OpenWeatherMap の `lang` パラメータ）。資格は日本国内のみ（v3） |
