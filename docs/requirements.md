# TimeKernel 要件定義書

## 概要

| 項目 | 内容 |
|------|------|
| アプリ名 | TimeKernel（タイムカーネル） |
| コンセプト | 学生の生活をこれ1つで管理。シンプル、爆速、共有がラク。 |
| ターゲット | 大学生・高校生（カップル、友達同士、グループ） |
| 競合との差別化 | TimeTreeより軽い、アカウント不要、学生特化 |

## 技術スタック

| レイヤー | 技術 |
|----------|------|
| フロントエンド | Expo + React Native + TypeScript |
| バックエンド | Firebase（Firestore / Anonymous Auth / Email Link Auth） |
| リアルタイム同期 | Firestore onSnapshot |
| Apple Watch | SwiftUI + expo-watch-connectivity |

## 認証

- 初回はアカウント登録なし（Firebase Anonymous Auth）
- 名前のみ端末ローカルに保存
- 共有時に名前が相手に表示される
- **メールリンク認証（任意）**: メールアドレスを登録するとuid引き継ぎが可能
  - 端末変更・再インストール時にメールリンクでログインして復元
  - 登録は任意（登録しなくても利用可能）

## コア機能

### 1. カレンダー表示

- 月表示（デフォルト）
- 日付タップで詳細表示（その日の予定一覧）
- 予定タイプごとの色分け（授業 / 予定 / バイト）
- 複数カレンダーの切り替え・統合表示

### 2. 予定管理

- 予定の追加 / 編集 / 削除
- 3種類の予定タイプ:
  - **授業（class）**: 時間割から自動反映
  - **予定（event）**: デート、遊び、プライベートなど
  - **バイト（shift）**: シフト（時給計算に連動）
- 各予定に含まれる情報:
  - タイトル
  - タイプ（class / event / shift）
  - 日付
  - 開始時刻・終了時刻
  - 時給（バイトのみ）
  - カラー
  - 作成者（uid）

### 3. 時間割機能

- 曜日 × 時限のグリッド表示
- 固定スケジュールとして登録
- カレンダーに自動反映（毎週の繰り返し予定として表示）
- **時限のカスタム設定**: ユーザーが自分の大学に合わせて各時限の時刻を設定可能
  - 例: 1限 = 9:00〜10:30、2限 = 10:40〜12:10
  - デフォルト6限構成（初期テンプレート）
  - ユーザーが時限の追加・削除が自由にできる
- 各科目の情報:
  - 科目名
  - 教室
  - カラー
- **公開設定**: 時間割ごとに公開 / 非公開を選択可能
  - 公開: 共有カレンダーのメンバー全員に表示
  - 非公開: 自分だけに表示

### 4. バイト管理・給料計算

- シフト登録（日付、開始時刻、終了時刻）
- 時給設定（複数バイト先対応）
- **深夜割増設定**: ユーザーが割増条件を設定可能
  - 割増開始時刻（デフォルト: 22:00）
  - 割増倍率（デフォルト: 1.25倍）
  - ON/OFF切り替え可能
- 自動計算:
  - 今月の合計勤務時間
  - 今月の見込み給料（深夜割増を反映）
- バイト集計画面で一覧表示

### 5. リアルタイム共有

- **複数人対応**（v1から対応、人数制限なし）
- カレンダーID発行（ランダム文字列）
- 共有方法:
  - QRコード表示・読み取り
  - リンクコピー・共有
- 1回読み込めば以降は自動同期（Firestore onSnapshot）
- 共有者の名前表示
- 1ユーザーが複数カレンダーを作成・参加可能
  - 例: 「彼女とのカレンダー」「サークル仲間のカレンダー」
- **管理権限**: 作成者が管理者
  - カレンダーの削除: 作成者のみ
  - メンバーの削除: 作成者のみ
  - メンバーの自主脱退: 誰でも可能
  - 予定の編集: メンバー全員可能
  - 予定の削除: 作成者のみ
  - 予定の追加: メンバー全員可能

### 6. Apple Watch対応

- 今日の予定表示
- 予定追加（音声入力対応）
- 今月のバイト代表示

## 複数カレンダー仕様

- ユーザーは複数のカレンダーを作成・参加できる
- カレンダーごとに名前を設定（例: 「俺と彼女」「ゼミ仲間」）
- メイン画面では全カレンダーの予定を統合表示（カレンダーごとにフィルタ可能）
- 各カレンダーにはメンバー一覧が表示される

## データ構造（Firestore）

```
users/
  └── {uid}/
        ├── name: "たろう"
        ├── email: "taro@example.com"                   // 任意。メールリンク認証用
        ├── calendars: ["calendarId1", "calendarId2"]  // 参加中のカレンダーID一覧
        └── settings/
              └── timetable/
                    └── periods: [                      // 時限カスタム設定
                          { period: 1, startTime: "09:00", endTime: "10:30" },
                          { period: 2, startTime: "10:40", endTime: "12:10" },
                          ...
                        ]
              └── shift/
                    ├── nightShiftEnabled: true         // 深夜割増ON/OFF
                    ├── nightShiftStartTime: "22:00"    // 深夜割増開始時刻
                    └── nightShiftMultiplier: 1.25      // 深夜割増倍率

calendars/
  └── {calendarId}/
        ├── name: "俺と彼女"
        ├── members: ["uid1", "uid2", "uid3"]
        ├── createdBy: "uid1"
        ├── createdAt: timestamp
        └── events/
              └── {eventId}/
                    ├── title: "バイト"
                    ├── type: "shift" | "class" | "event"
                    ├── date: "2026-03-15"
                    ├── startTime: "18:00"
                    ├── endTime: "22:00"
                    ├── hourlyWage: 1200        // バイトのみ
                    ├── color: "#FF5733"
                    ├── createdBy: "uid1"
                    └── createdAt: timestamp

timetables/
  └── {uid}/
        └── {timetableId}/
              ├── calendarId: "calendarId1"     // 紐付くカレンダー（null = 個人のみ）
              ├── isPublic: true                 // 公開/非公開
              └── slots/
                    └── {dayOfWeek}_{period}/
                          ├── subject: "経済学入門"
                          ├── room: "A棟301"
                          └── color: "#3498db"
```

### データ構造の補足

- `users/{uid}/calendars`: ユーザーが参加しているカレンダーのID配列。カレンダー一覧の高速取得用。
- `timetables`: ユーザー個人に紐付く。`isPublic: true` かつ `calendarId` が設定されている場合、該当カレンダーのメンバーに表示。
- `events`: カレンダーのサブコレクションとして格納。カレンダーメンバー全員に表示。

## 非機能要件

| 項目 | 内容 |
|------|------|
| 対応OS | iOS / Android |
| 広告 | なし（将来的にプレミアム検討） |
| オフライン | v1では対応しない（v2以降で検討） |
| 同期速度 | 1秒以内（Firestore onSnapshot） |
| セキュリティ | Firestore Security Rulesで共有カレンダーメンバーのみ読み書き許可 |

## v1スコープ外（v2以降）

- オフライン対応（ローカルキャッシュで閲覧・追加、オンライン復帰時に同期）
- MCP対応（Claude / ChatGPT連携）
- ウィジェット（iOS / Android）
- 通知・リマインダー

- [x] 時限数 → **デフォルト6限、ユーザーが自由に追加・削除可能**

- [x] 共有人数 → **v1から複数人対応、人数制限なし**
- [x] カレンダー数 → **1ユーザー複数カレンダー対応**
- [x] 時間割の公開設定 → **時間割ごとに公開/非公開を選択可能**
- [x] オフライン → **v1では対応しない**
